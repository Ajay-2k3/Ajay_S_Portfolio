## 💻 Local Development

To run this portfolio locally:

```bash
# 1. Clone the repository
git clone https://github.com/Ajay-2k3/Ajay_S_Portfolio.git
cd Ajay_S_Portfolio

# 2. Install dependencies
npm install

# 3. Start the local development server
npm run dev

# 4. Build for production
npm run build

# 5. Run type safety check
npx tsc --noEmit
```
